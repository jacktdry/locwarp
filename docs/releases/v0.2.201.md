# LocWarp for macOS v0.2.201 — Apple Silicon Stable Release

[繁體中文](#繁體中文) · [English](#english)

## 繁體中文

這是 [LocWarp 原版 v0.2.200](https://github.com/keezxc1223/locwarp) 的**非官方 macOS 維護版**，首次以 GitHub **正式穩定版**提供 Apple Silicon（M1 及更新的 M 系列）原生應用程式。支援使用 USB 或原生 Wi-Fi 連接 iPhone，模擬位置、導航及多點路線。

> ⚠️ **穩定版不等於 Apple 已驗證。** 本安裝檔僅採 **ad-hoc 簽章，沒有 Apple Developer ID 簽章／Notarization（公證）**。Apple 未驗證本 App；macOS Gatekeeper 可能阻止開啟。若不信任下載來源或無法核對完整性，請不要開啟。**僅支援 Apple Silicon ARM64；不支援 Intel Mac／Android。** iPad 與所有 iOS 版本未經完整實機驗證。

### 本次改善

- **多台 iPhone 連線穩定性**：增強 macOS 原生 Wi-Fi／USB RSD 與 DVT 建立、USB 優先、僅對明確核准的裝置自動連線、斷線復原及資源釋放。真實測試包含 USB → Wi-Fi 備援和 Idle Wi-Fi → USB 的反向切換。
- **GPS 路線接續**：雙手機在 USB 斷線後，Wi-Fi 裝置可接手進行中的路線；重新連線後可重新加入。GPS 模擬結束後已測試清除及恢復裝置真實位置。
- **關窗仍維持路線**：Electron GUI 關窗後，後端及模擬不中止；重新開窗會以唯讀快照恢復路徑及進度。修正較舊快照覆蓋較新 WebSocket 座標、結束後殘留舊路線畫面。
- **節電行為**：LocWarp 開啟期間阻止 Mac **因閒置而進入系統睡眠**，允許螢幕關閉／鎖定，正常退出後釋放電源保護。手動睡眠與闔蓋不在保證範圍內。
- **隔離 GUI 測試工具**：加入雙假裝置路線測試，不會操作實體 iPhone GPS，回歸驗證視窗重開及路線結束時的 UI 狀態。

### 測試及已知範圍

- **94 項後端測試、28 項 Electron 測試通過**；ARM64 打包後端自我檢查、程式碼簽章完整性及安裝檔校驗列入建置驗證。
- 兩台實體 iPhone（iOS 27.0.1）完成 USB／Wi-Fi 實機切換、GPS 路線備援與還原驗證；GUI 動態路線關窗／重開在 **兩台假裝置**整合測試通過。**未宣稱真實 iPhone 活動 GPS 時的 GUI 視覺驗收已完成**。
- `⌘W`／`⌘Q` 快捷鍵及 Dock 點擊的實際人工操作尚未逐項測試；窗口生命週期已透過程式事件／macOS 系統 App 生命週期測試。三台裝置同時運作、iPad 與不同 iOS 版本的全面測試仍未完成。Mac 整機睡眠後恢復不屬於本版承諾使用情境。

### 安裝與首次開啟

1. 從這個 GitHub Release 下載 **`LocWarp-0.2.201-mac-arm64.dmg`**，用 `SHA256SUMS.txt` 核對 SHA-256。只下載本倉庫的正式附件。
2. 打開 DMG，將 **LocWarp.app 拖曳至「應用程式」（Applications）**，從應用程式資料夾開啟，**不要直接在 DMG 裡執行**。
3. 如果顯示「無法驗證開發者」或 Apple 無法檢查惡意軟體：確認來源與檔案完整性後，可前往 ** → 系統設定 → 隱私權與安全性 → 安全性 → 強制打開（Open Anyway）**，只為 LocWarp 建立例外。**不要停用 Gatekeeper／SIP，不要移除 quarantine**。如果警告說 App 已損壞或含惡意程式，**停止並回報**，不要繞過警告。
4. 使用可傳資料 USB 線，解鎖 iPhone、完成「信任這部電腦」；iOS 16+ 開啟開發者模式。需 Wi-Fi 時先經 USB 配對，設定 Finder「連接 Wi-Fi 時顯示此裝置」並確保同網路。
5. 使用模擬後記得按 **「一鍵還原」／「全部還原」**，而非只按「停止」；`⌘W` 關窗**不會**停止已啟動的 GPS 模擬，`⌘Q` 才是退出 App。

## English

This is the **unofficial macOS maintenance fork** of [original LocWarp v0.2.200](https://github.com/keezxc1223/locwarp), now published as a **stable macOS release** for Apple Silicon (M1 and newer). It provides USB / native Wi-Fi iPhone connections, location simulation, navigation and multi-stop routing.

> ⚠️ **Stable refers to functionality and testing, NOT Apple verification.** This build has an **ad-hoc signature only: no Apple Developer ID signature and no notarization**. Apple has not verified the software; Gatekeeper may block it. Verify the source and the checksum before considering an app-specific exception. **Apple Silicon ARM64 only; no Intel Mac or Android support.** iPad and all iOS versions have not been fully hardware-tested.

### What's improved

- **Multi-phone connection reliability:** native macOS USB/Wi-Fi RSD, device-specific opt-in auto-connect, USB preference, recovery, clean handle ownership. Physical tests covered USB → Wi-Fi backup and idle Wi-Fi → USB re-upgrade.
- **GPS continuity:** real two-iPhone route failover after USB loss and location restoration were tested.
- **Window rehydration:** closing the GUI leaves the backend running; reopening restores active routes through read-only snapshots. Stale HTTP snapshots no longer rewind newer WebSocket positions or leave old route overlays after completion.
- **Idle sleep prevention:** prevents automatic Mac system sleep while LocWarp remains running, while allowing the screen to lock or turn off. Quit releases this protection; manual sleep/lid closure is not prevented.
- **Reproducible isolated tests:** synthetic dual-phone backend tests GUI route rehydration without writing real iPhone GPS.

### Validation and limitations

- **94 backend tests and 28 Electron tests passed**, plus ARM64 packaging, frozen-backend self-test and signed bundle validation during the build.
- Real iPhone 15 Pro devices (iOS 27.0.1) were used to validate USB/Wi-Fi switching, route handoff and GPS restoration. **Active-route GUI visual testing used synthetic devices**, not live phone GPS. Literal ⌘W, ⌘Q and clicking the Dock were not physically tested (lifecycle event and OS-level tests were performed).
- Three devices at once, all iOS/iPadOS versions, iPad hardware and Mac system sleep/wake route continuation remain outside the fully verified scope.

### Download, install and first launch

1. Download **`LocWarp-0.2.201-mac-arm64.dmg`** and verify its SHA-256 against `SHA256SUMS.txt` (Apple Silicon only).
2. Open the DMG and drag **LocWarp.app into Applications**. Launch it from Applications, **not directly from the mounted disk image**.
3. If macOS blocks it because the developer is unidentified or it cannot check for malware, after verifying the download you may choose **Apple menu → System Settings → Privacy & Security → Open Anyway** for this individual app. **Never disable Gatekeeper/SIP or strip quarantine.** If macOS reports malware or a damaged app, **stop** and report the issue rather than bypassing the warning.
4. Pair your unlocked iPhone over a data USB cable and approve Finder/iPhone Trust; enable Developer Mode on iOS 16+. For Wi-Fi, enable Finder's **Show this device when on Wi-Fi** while paired and keep phone/Mac on the same network.
5. **Stop is not Restore.** Use **Restore** / **Restore all** to return to real GPS after simulation. Closing the window with ⌘W does **not** stop simulated movement; ⌘Q quits the app.
