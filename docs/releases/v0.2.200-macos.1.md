# LocWarp for macOS v0.2.200-macos.1 — Apple Silicon 公開測試版 / Public Preview

## 繁體中文

這是基於 [LocWarp 上游 v0.2.200](https://github.com/keezxc1223/locwarp) 製作的**非官方 macOS 維護版本**，支援透過 USB 或原生 Wi-Fi 連接 iPhone，模擬 GPS 位置、導航及多點路線。

**適用：Apple Silicon（M1 及更新的 M 系列）Mac、iPhone／iPad。** **不支援 Intel Mac 或 Android**；iPad 尚未完成完整實機驗證。

> ⚠️ **公開測試版，未經 Apple 公證。** 此 App 僅採 ad-hoc 簽章，**沒有 Apple Developer ID 簽章／Notarization**，macOS 可能封鎖首次開啟。請確認下載來源和檔案完整性；此版本並非 Apple 驗證過的正式發行版。

### 下載與安裝

1. 下載下方附件 **`LocWarp-0.2.200-macos.1-mac-arm64.dmg`**（Apple Silicon 專用），可使用 `SHA256SUMS.txt` 核對檔案完整性。
2. 連按兩下 DMG，將 **LocWarp.app 拖曳至「應用程式（Applications）」資料夾**，再從 Finder「應用程式」啟動，**不要直接在 DMG 內執行**。
3. **如果 macOS 出現「無法驗證開發者」／「Apple 無法檢查是否包含惡意軟體」**：在確認檔案來源可信且未遭竄改後，先關閉提示，再前往 ** → 系統設定 → 隱私權與安全性 →「安全性」→「強制打開」（Open Anyway）**，再確認「打開」，必要時輸入登入密碼。按鈕通常在嘗試開啟 App 後約 **一小時內**出現；若找不到，先重新嘗試開啟一次 LocWarp。這是針對單一 App 的例外，**不需要關閉 Gatekeeper 或 SIP**。
4. **重要**：如果 macOS 指出 App **已損壞、含惡意軟體或會損壞電腦**，不要略過警告；請重新檢查來源，並在 GitHub [回報問題](https://github.com/jacktdry/locwarp-macos/issues)。

Apple 官方說明：[在 Mac 上安全地開啟 App](https://support.apple.com/zh-tw/102445)／[如何「強制打開」](https://support.apple.com/zh-tw/guide/mac-help/mh40617/27/mac/27)。執行未經公證的程式具有安全風險，請審慎評估。

### iPhone 連線與基本使用

1. **首次 USB 配對**：使用可傳輸資料的 USB 線連接 iPhone 與 Mac，解鎖手機並按「信任這部電腦」；在 Finder 確認裝置已顯示。iOS 16+ 至 **設定 → 隱私權與安全性 → 開發者模式** 啟用，依提示重新啟動並確認；若選項或定位服務不可用，可能需要相容的 Xcode／DDI 裝置準備。
2. **USB 操作**：開啟 LocWarp，透過 USB 掃描／連接已配對裝置，確認成功連線。
3. **Wi-Fi 操作**：先保持 USB 連線，於 **Finder → iPhone →「一般」** 勾選 **「連接 Wi-Fi 時顯示此 [裝置]」** 並按「套用」。拔除 USB 後讓 Mac 與手機在同一 Wi-Fi，於 LocWarp 的 **「macOS Wi-Fi 連線」按「掃描裝置」**並連接。此模式不需管理員權限。
4. **模擬位置**：選擇 **「瞬間移動」** 並指定地點／座標；或使用 **「導航移動」** 和 **「多點路徑」** 設定路線、途經點與速度後開始。
5. **結束定位**：**「停止」不等於清除虛擬 GPS**。用完請使用 **「一鍵還原」** 恢復手機真實定位；多支裝置請逐一確認或選擇「全部還原」。
6. **視窗行為**：**⌘W** 關閉視窗時後端可能仍持續移動手機 GPS，從 Dock 開啟會重新同步路線；**⌘Q** 才會退出 App。不要將關閉視窗視為結束模擬。

更詳細的圖文式操作步驟與排除方式：[繁體中文 README](https://github.com/jacktdry/locwarp-macos/blob/main/README.md)／[macOS 技術說明](https://github.com/jacktdry/locwarp-macos/blob/main/docs/MACOS.md)。**請勿將本機控制 API（TCP 8777）直接公開至 Internet。**

### 本版更新與驗證

- macOS 原生 USB、Wi-Fi RSD、Apple Silicon ARM64 DMG／ZIP。
- 支援 ⌘W 關窗、Dock 重開與路線／途經點狀態恢復；重新同步狀態不會自行重新規劃路線或發出 GPS 變更指令。
- 強化 LAN 存取限制及手機 PIN 嘗試次數限制。
- **23 項 Python、16 項 Electron 測試通過**；已從本版 DMG 在 Apple Silicon 安裝並冷啟動，後端 API 正常。本次驗證有 **1 支 iPhone 經 Wi-Fi 成功連線**；先前版本曾驗證兩支 iPhone 同時連線與瞬移。
- **尚待實機驗收**：在本版進行中的路線使用 ⌘W → Dock 恢復、兩支 iPhone 同時連線的完整重測。未宣稱 iPad 或所有 iOS 版本均已實測。

## English

This is a **community-maintained, unofficial macOS port** based on [original LocWarp v0.2.200](https://github.com/keezxc1223/locwarp), offering USB and native Wi-Fi iPhone location simulation, navigation, and multi-point routes.

**Platform: Apple Silicon Macs (M1 or newer M-series), iPhone/iPad. Intel Macs and Android are not supported.** iPad has not been fully validated with physical hardware.

> ⚠️ **PUBLIC PRE-RELEASE — NOT APPLE-NOTARIZED.** The App is **ad-hoc signed**, without an Apple Developer ID signature or notarization. macOS Gatekeeper may block first launch. Only run files downloaded from a verified source and checked for integrity; this is not an Apple-verified stable release.

### Download and install

1. Download **`LocWarp-0.2.200-macos.1-mac-arm64.dmg`** from the assets below. Use `SHA256SUMS.txt` to check file integrity if desired.
2. Double-click the DMG and **drag LocWarp.app to Applications**. Launch it from **Finder → Applications**, **not from inside the DMG**.
3. **If macOS says the developer cannot be verified or Apple cannot check for malicious software**: only after verifying the source and integrity, dismiss the warning, open ** → System Settings → Privacy & Security → Security → Open Anyway**, then confirm **Open**, entering your password if prompted. The button typically appears for **about an hour after attempting to open the App**. If absent, try opening LocWarp again. This creates an exception for just this app; **do not disable Gatekeeper or SIP**.
4. **Important**: if macOS says the App **is damaged, contains malware, or will damage your computer**, do **not** bypass the warning. Verify the download and [report the issue](https://github.com/jacktdry/locwarp-macos/issues).

Apple documentation: [Open apps safely](https://support.apple.com/en-ie/102445) / [Open an app by overriding security settings](https://support.apple.com/en-au/guide/mac-help/mh40617/mac). Running non-notarized applications involves security risks.

### Connect an iPhone and use LocWarp

1. **Initial USB pairing**: connect your unlocked iPhone using a data-capable cable. Tap **Trust This Computer** and confirm the device appears in Finder. On iOS 16+, enable **Settings → Privacy & Security → Developer Mode**, reboot and confirm. Compatible Xcode / Developer Disk Image setup may be needed.
2. **USB**: open LocWarp, use the USB scan/connect controls and select the trusted phone.
3. **Wi-Fi**: while USB is still connected, in **Finder → iPhone → General**, enable **Show this [device] when on Wi-Fi** and click **Apply**. Unplug USB; keep both devices on the same Wi-Fi. In LocWarp, use **macOS Wi-Fi connection → Scan devices**. No administrator privileges are required.
4. **Change location**: use **Teleport** to pick a location or enter coordinates; use **Navigate** or **Multi-point Route** to set a route, waypoints and speed and start moving.
5. **Return to real GPS**: **Stop** stops movement but may leave simulated GPS active. Click **Restore** to clear the virtual location; for multiple phones use per-device Restore or **Restore all**.
6. **Window behavior**: **⌘W** closes the window but keeps the backend running, so GPS routes may continue; reopen from the Dock to recover the route view. **⌘Q** quits. Closing a window does **not** restore real GPS.

More detail: [English README](https://github.com/jacktdry/locwarp-macos/blob/main/README.en.md) / [macOS technical notes](https://github.com/jacktdry/locwarp-macos/blob/main/docs/MACOS.md). **Never expose the local API (TCP port 8777) directly to the Internet.**

### Highlights and verification

- Native macOS USB/Wi-Fi RSD, ARM64 DMG/ZIP, ⌘W/Dock window lifecycle, and read-only route/waypoint restoration after reopening or reconnecting.
- LAN desktop API restrictions and phone PIN rate limiting.
- **23 Python and 16 Electron tests passed**; this exact DMG installed and cold-launched on an Apple Silicon Mac, with backend HTTP 200 and **one Wi-Fi iPhone connected**. Two Wi-Fi iPhones and teleportation were previously verified on an older build.
- **Pending real-device regression checks**: active route recovery using ⌘W → Dock on this exact build, and two-phone concurrent Wi-Fi reconnection. Full iPad/all-iOS-version compatibility is not claimed.
